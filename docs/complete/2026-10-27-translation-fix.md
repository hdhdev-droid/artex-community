# 2026-10-27 미번역 수정 및 로컬 Docker 반영

## 완료 결과

[추가 검토](2026-10-27-translation-followup-audit.md)에서 확정한 MCP·스킬·에이전트 삭제 표시, Auto 설명, 브라우저 제목 문제를 수정했다. 기존 한국어·영어·중국어·스페인어·일본어 번역을 재사용한다.

로컬 접속 주소는 **http://localhost:5173/system/mcp/** 이다. 현재 앱은 공개 v1.0.0 기반의 로컬 수정 빌드 **`1.0.0+local.i18n.1`** 이며 이미지 이름은 `artex-community:1.0.0-i18n.1`이다. 공개 GitHub 릴리스·태그·이미지는 변경하지 않았다.

## 사용자 데이터 보호

- 기존 이름·설명과 정확히 일치하는 시스템 기본값만 번역하는 조건을 유지했다. 사용자 지정 이름·설명, 첨부 파일명, 증거 원문, 모델 입력과 과거 보고서는 수정하지 않는다.
- DB와 진단 runner 컨테이너는 재생성하지 않았다. 앱만 수정 이미지로 교체하고 기존 `runtime` 인증 볼륨과 `data` 볼륨을 재사용했다.
- 전환 전후 JWT와 암호화된 ChatGPT 인증 파일의 SHA-256이 일치한다. 인증 내용은 출력·전송하지 않았다.
- 저장 파일 6개의 내용 지문이 일치한다. DB 65개 테이블 중 62개는 전체 행 지문이 일치하며, `agents` 8행과 `mcp_servers` 2행은 정상 기동에 따른 `updated_at`만 변경됐다. `server_logs`는 28행에서 36행으로 증가했다.
- 언어 저장·권한 변경·삭제·샘플 생성·DB 초기화/리셋은 수행하지 않았다. 삭제 확인창은 표시만 확인하고 취소했다. 정상 앱 기동 처리는 기존 승인 범위에서 수행했다.

## 빌드·테스트·실행 확인

- 프런트엔드 테스트 **11개 파일, 49개 테스트 통과**. 위 16개 신규 회귀 검증을 포함한다.
- 기존 5개 언어의 번역 키 **4,591개**가 일치한다.
- Next.js 정적 빌드와 TypeScript 검증 통과. Go의 `embedui` 빌드 및 실행 파일 버전 확인 통과. 백엔드 로직 수정은 없으며 전체 Go/DB 테스트는 이번에 반복하지 않았다.
- 빌드 컨테이너는 실서비스 DB에 연결하지 않았다. Go 빌드는 기존 모듈 캐시와 네트워크가 차단된 컨테이너를 사용했다. 정식 이미지의 도구 환경을 그대로 사용하고 수정된 실행 파일만 덧붙였다.
- 첫 실제 화면 확인에서 Next.js 정적 메타데이터가 제목을 덮어쓰는 문제가 발견되어, 제목 관리 주체를 하나로 통일한 뒤 전체 프런트엔드 테스트·정적 빌드·패키징을 다시 완료했다.
- 최종 실행 이미지 ID: `sha256:1730d7c9280ef37d742f678811be4d6373edd5d0a8e25918eb94a811cbf88282`. 실행 컨테이너와 로컬 이미지가 일치한다.
- `/api/health`: `ok: true`, 버전 `1.0.0+local.i18n.1`. 비로그인 작업 API: HTTP 401. 내부 진단 서비스 상태: `ok`. 마지막 기동 로그에서 error/failed/fatal/panic 0건, 자동 재시작 0회.
- 외부 Chrome의 기존 로그인으로 실제 한국어 MCP·스킬 상세·Auto 설명·삭제 확인 문구를 확인했다. 최종 이미지에서는 새 탭 및 화면 이동 후에도 한국어 제목을 유지하고 head의 title·description이 각각 하나임을 확인했다. 확인한 최종 화면의 브라우저 오류는 0건이다.
- 5개 언어 검증은 실제 React 컴포넌트의 격리 렌더링 테스트로 수행했다. 운영 DB의 설치 언어는 바꾸지 않았으며 실제 브라우저 확인은 기존 한국어 설정을 사용했다. 외부 OAuth·모델·Splunk 호출, 실제 진단, 권한 변경 알림·삭제 완료 알림을 유발하는 실데이터 수정은 하지 않았다.
- 빌드 로그·비교 지문·실행 상태·한국어 화면 증거는 Git 제외 경로 `work/translation-fix/`에 보관한다.

## 실행과 남은 경계

```sh
docker compose -f docker-compose.dev.yml -f docker-compose.local-release.yml -f docker-compose.local-patch.yml up -d --no-deps --no-build backend
```

위 세 파일로 실행해야 로컬 수정 이미지가 유지된다. 정식 v1.0.0으로 복귀하려면 마지막 파일을 제외한다. 로컬 버전 접미사는 정식 배포본과 구분하고 앱의 한 번 클릭 업데이트로 수정본이 덮어써지는 것을 막기 위한 것이다.

확정된 미번역 항목은 반영했다. 앞선 검토에서 후보로만 남긴 승인 기록·대시보드의 과거 실행 이름은 증거 원문과의 구분이 필요하므로 이번 범위에 임의로 포함하지 않았다. 현재 변경은 로컬에만 있으며 커밋·푸시·새 공개 릴리스는 수행하지 않았다.
