# 2026-10-27 v1.0.0 미번역 추가 검토

## 후속 반영

사용자 승인 후 아래 확정 항목을 수정하고 로컬 빌드·테스트·Docker 반영까지 완료했다.
세부 결과는 [미번역 수정 완료 기록](2026-10-27-translation-fix.md)에 정리했다. 아래 내용은 수정 전 조사 결과로 보존한다.

## 범위

사용자가 제보한 MCP 권한 목록을 현재 실행 중인 localhost:5173의 v1.0.0 한국어 화면에서 확인했다. 스킬 상세와 에이전트 목록도 직접 확인하고, 관련 표시 경로와 기존 언어 감사 기록을 소스로 대조했다. 앱 코드 수정·빌드·테스트·DB 변경·컨테이너 재기동·외부 연결 실행은 하지 않았다. 이번 파일은 검토 기록이며 수정 완료 기록이 아니다.

## 기존 번역과 구분

- 기본 에이전트 8종의 이름 번역은 한국어·영어·중국어·스페인어·일본어 메시지 파일에 이미 존재한다. 번역 키가 있다고 실제 모든 화면이 그 키를 사용하는 것은 아니다.
- 에이전트 목록의 목표 분해·계획 수립·메인·실행·침투 테스트·취약점 재검증 이름은 실제로 한국어가 표시됐다. Auto 설명은 위 기준값 오류로 예외다.
- 도구 화면은 `useAgentLabels`를 이미 사용한다. 대화의 에이전트 그룹·선택 목록도 번역 함수를 거친다. 검색에 걸린 대화·세션·메시지의 일부 `a.name`은 첨부 파일 이름이므로 번역 대상이 아니다.
- `Auto`는 현재 5개 언어에서 공통으로 사용하는 이름이다. `ScopeSentry`, `browser`, HTTP, STDIO, 스킬·도구 식별자, 사용자 지정 이름은 무조건 번역할 대상이 아니다.
- 승인 기록·대시보드의 `agent_name` 직접 표시는 추가 확인 후보다. 기록된 실행 이름·역할 키·사용자 이름을 구분해야 하며 이번에는 재현 데이터 없이 확정 결함으로 분류하지 않았다.

## 수정 및 후속 검증 기준

1. MCP·스킬·삭제 UI에 기존 번역 함수를 재사용하고 Auto 기준값을 정정한다. 새 라이브러리나 DB 마이그레이션은 필요 없다.
2. 기본값과 정확히 일치하는 시스템 이름·설명만 번역한다. 사용자 편집 이름, 증거, 파일명, 과거 기록 원문은 보존한다.
3. 후속 검증은 번역 키 정합성뿐 아니라 MCP·스킬 상세/생성·에이전트 삭제 UI·Auto 설명의 5개 언어 표시와 사용자 수정값 보존을 포함해야 한다. 실제 권한 변경·삭제 대신 표시 경로를 검증한다.
4. 현재 실행 중인 이미지는 고정된 v1.0.0이므로 소스 수정만으로 화면이 바뀌지 않는다. 수정 반영 후 별도로 승인된 빌드·검증·이미지 배포가 필요하며 기존 v1.0.0 릴리스 태그를 덮어쓰지 않는다.

이전 감사는 [언어 감사 기록](../todo/2026-10-20-language-audit.md), 현재 실행 환경은 [로컬 v1.0.0 전환 기록](2026-10-27-local-v1.0.0-deployment.md)을 참조한다. 이번 확인은 관련 에이전트 표시 경로 중심이며 전체 화면·모든 데이터 상태의 무누락을 보증하지 않는다.
