# 2026-11-04 v1.0.1 발행 결과

- 사용자 요청에 따라 번역 수정과 릴리스 준비를 커밋하고 `main`에 푸시했다. 릴리스 태그 `v1.0.1`은 `9e956aba329345990f0e58481de58a3b8894f04e`를 가리킨다.
- [main 웹 검사](https://github.com/hdhdev-droid/artex-community/actions/runs/41796201294), [문서 검사](https://github.com/hdhdev-droid/artex-community/actions/runs/41796201061), [백엔드 CI](https://github.com/hdhdev-droid/artex-community/actions/runs/41796200972)가 통과했다.
- [정식 릴리스 워크플로](https://github.com/hdhdev-droid/artex-community/actions/runs/41796545256)의 프런트엔드, 백엔드, 5개 플랫폼 패키지, Docker 및 릴리스 단계가 모두 통과했다. GitHub Actions의 테스트 전용 임시 DB 생성·초기화는 별도 허용받았다.
- [v1.0.1 정식 릴리스](https://github.com/hdhdev-droid/artex-community/releases/tag/v1.0.1)가 공개됐고, 플랫폼 ZIP 5개와 `SHA256SUMS`, `VERSION`, `upstream.json`이 첨부된 것을 확인했다. 다운로드 파일의 체크섬을 별도로 계산하지는 않았다.
- 공개 `ghcr.io/hdhdev-droid/artex-community:v1.0.1` 매니페스트에서 Linux amd64와 arm64 항목을 확인했다. 실제 사용자 환경에서 이미지 실행은 확인하지 않았다.
- 기존 운영 DB·인증 정보·로컬 컨테이너는 변경하지 않았다. 실제 OAuth 및 외부 서비스 연결과 실제 진단도 수행하지 않았다.
