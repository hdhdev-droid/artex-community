# 2026-10-24 v1.0.0 공개 릴리스

## 요청과 반영 범위

사용자 요청에 따라 누적 community 변경을 `hdhdev-droid/artex-community`에 커밋·푸시하고 `v1.0.0` 릴리스와 GitHub Actions 결과를 확인한다. 대상은 `main`이며 기존 `v1.0.0` 태그는 없음을 확인했다. 운영 DB·인증 파일·실제 OAuth 로그인은 변경하지 않는다.

커밋에는 보안 진단 기능 이전, 5개 언어, 온보딩·OpenRouter/ChatGPT OAuth, 인증 파일 영속화, community 버전·업데이트·릴리스 구성과 완료 기록을 포함한다. 상세 기능·로컬 검증 범위는 [릴리스 준비 기록](2026-10-24-release-readiness.md)을 참조한다.

## 발행 전 보완

- Git 커밋 대상에서 `.secrets`, `.env`, JWT·OAuth 파일, 로컬 데이터·검증 산출물이 제외되는 것을 확인했다. 비밀 문자열 패턴 검사에서 탐지된 개인키 표시는 `offensivereview/model_test.go`의 합성 비밀 제거 테스트 픽스처였다.
- 기존 프런트엔드 CI의 Biome 형식·import 순서를 정리했다. Git 기준 변경 범위 밖의 파일에는 내용 변경이 없으며 Windows 줄바꿈 차이는 정규화된다.
- `offensive/assessments/page.tsx`, `onboarding-entry.tsx`의 의도적인 갱신 의존성을 설명하고 유지했다. `onboarding/page.tsx`의 저장소 접근 실패 처리에 이유를 기록했다. `generated-message-i18n.ts`의 전역 이름과 겹치는 지역 함수명을 바꿨다.
- 로컬 Biome 오류 0 확인. 경고·정보 수준 항목은 기존 CI 기준과 동일하게 유지한다.
- 문서 링크 검사기가 실제로 존재하는 HTML 앵커를 인식하도록 보완했다. 상류 안내의 고정 링크를 유지하며 코드 블록 안 예시는 검사 대상에서 계속 제외한다.
- 문서 89개, 파일 참조 767개, 앵커 89개 검사에서 깨진 참조 0. 이전 로컬 빌드 산출물의 HTML 38개에서 비의도적 한자 0. 탐지 지표와 소스·CI 경로 일치 검사 통과. 이번 검사에서 프런트엔드 빌드를 새로 실행하지 않았다.

## 발행 상태

- 누적 변경 334개 파일을 커밋 `5ddfc15712b77996ea492045f3370cbdcfe71480`로 생성하고 `origin/main`에 푸시했다.
- 원격 저장소는 공개 포크이며 보관·비활성 저장소가 아니다. 공개 API에서 6개 워크플로의 상태는 `active`이지만, 푸시 이후 Actions 실행과 해당 커밋의 체크는 모두 0건이다. 따라서 GitHub 빌드 성공으로 기록하지 않는다.
- 현재 GitHub 브라우저는 로그아웃 상태이고, SSH 푸시 이외의 GitHub 설정 변경용 인증은 없다. 사용자에게 GitHub 로그인과 저장소 Actions 허용 상태 확인을 요청했다. 미실행의 정확한 설정 원인은 인증 후 확인해야 한다.
- `v1.0.0` 태그·GitHub Release·GHCR 이미지는 아직 발행하지 않았다. Actions 설정 확인 후 검증을 재실행하고, 통과한 커밋에 태그를 붙여 릴리스 결과·산출물·이미지 플랫폼을 확인한다. 실제 OAuth 로그인은 사용자 수행 범위로 유지한다.
