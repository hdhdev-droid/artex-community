# 2026-10-27 v1.0.0 원격 검증과 발행

## 요청과 실행 범위

사용자가 승인한 `hdhdev-droid/artex-community` 커밋·푸시·v1.0.0 릴리스 작업을 외부 Chrome에서 이어간다. 기존 로컬 DB와 인증 정보는 변경하지 않으며 실제 OAuth 로그인·외부 서비스 연동 검증은 이번 작업에 포함하지 않는다.

## Actions 미실행 원인과 조치

- [10월 24일 기록](2026-10-24-v1.0.0-publication.md)의 원격 미실행 원인은 GitHub가 포크 생성 시 워크플로 실행을 비활성화한 상태였음이 관리자 화면에서 확인됐다.
- 사용자의 실행 직전 승인 후 `I understand my workflows, go ahead and enable them`으로 활성화했고 `Actions Enabled.` 표시를 확인했다.
- 기본 토큰 권한이나 외부 기여자 승인 정책은 변경하지 않았다. 워크플로에 이미 선언된 작업별 권한을 사용한다. 정기 외부 링크 점검 워크플로는 기존 비활성 상태를 유지한다.
- 기능 변경 커밋은 `5ddfc15712b77996ea492045f3370cbdcfe71480`, 이전 발행 준비 기록은 `3f95c38d1d9d36251fea7c160995af8d2d29b9ba`이다.

## 원격 검증과 발행 상태

- `MAINTAINING.md`, `MAINTAINING.en.md`의 발행 안내를 community 버전·이미지·현재 6개 작업 기준으로 맞췄다. 이전 상류 태그 예시와 미커밋 상태 안내를 정리하고, `README.ko.md`에서 로컬 검증과 실제 OAuth 검증을 구분하도록 수정했다.
- [일반 CI](https://github.com/hdhdev-droid/artex-community/actions/runs/40440072356)의 Go 빌드·정적 검사·테스트 및 6개 패키지별 DB 통합 검증과 [문서 검사](https://github.com/hdhdev-droid/artex-community/actions/runs/40440072402)가 발행 대상 커밋에서 통과했다.
- [릴리스 수동 검증](https://github.com/hdhdev-droid/artex-community/actions/runs/40439726260)은 4분 28초에 성공했다. 프런트엔드 33개 테스트·5개 언어 키 검사·정적 빌드, 백엔드 오프라인·DB·경쟁 상태 검사, 5개 플랫폼 ZIP 패키징이 통과했다. 수동 실행의 Docker·Release 작업은 설계대로 건너뛴다.
- 수동 검증 커밋 `b52992b` 이후 발행 대상 `b4b1118196a5db6d6de8c3e7fc5e291da9f8a6f2`까지 변경은 위 문서 4개뿐이다. `v1.0.0` 태그를 이 대상에 생성·푸시했다. 정식 태그 실행은 같은 코드에서 전체 릴리스 검증을 다시 수행한다.
- 기존 Actions의 Node 20 런타임이 GitHub에서 Node 24로 강제 전환된다는 경고와 ubuntu-latest의 Ubuntu 26 전환 안내가 있었다. 검증 실패는 아니며, Action 메이저 버전 정리는 별도 유지보수 항목으로 남긴다.

## 최종 발행 결과

- [정식 릴리스 실행](https://github.com/hdhdev-droid/artex-community/actions/runs/40440363724)과 [탐지 규칙 검증](https://github.com/hdhdev-droid/artex-community/actions/runs/40440363843)이 모두 성공했다. 정식 실행의 백엔드·프런트엔드·5개 플랫폼 빌드·Docker·Release 작업이 모두 완료됐다.
- [ARTEX Community v1.0.0](https://github.com/hdhdev-droid/artex-community/releases/tag/v1.0.0)은 **2026-10-27 11:57:08 KST**에 공개됐으며 `Latest` 정식 릴리스다. 초안·사전 릴리스가 아니다. 발행 태그는 `b4b1118196a5db6d6de8c3e7fc5e291da9f8a6f2`를 가리킨다.
- 배포 첨부물은 8개: Linux amd64/arm64, macOS amd64/arm64, Windows amd64 ZIP 5개와 `SHA256SUMS`, `VERSION`, `upstream.json`. GitHub 화면의 Assets 10에는 자동 생성 소스 ZIP·tar.gz 2개가 추가로 포함된다.
- 로그인 없이 8개 배포 파일을 실제 다운로드했다. ZIP 5개 모두 공개 `SHA256SUMS`와 일치하며, 각 ZIP의 VERSION은 `1.0.0`, 상류 기준은 `fdfb7a17b7da5e2de716c0e98475ec77a41c64c6`이다. 실행 파일·인증 운영 안내 포함 및 로컬 인증 파일 제외도 확인했다.
- `ghcr.io/hdhdev-droid/artex-community:v1.0.0`과 `latest`가 모두 게시됐다. 두 태그의 이미지 인덱스는 `sha256:93f525020c73f19bca050584c752920969173de7f3324ec2efe27d46be28f41a`로 같고 `linux/amd64`, `linux/arm64`를 포함한다. 사용자 자격 증명 없이 익명으로 두 태그의 매니페스트 조회를 확인했다.
- 다운로드·체크섬·패키지 검증 결과와 화면 증거는 Git 제외 경로 `work/release-publication/`에 보관한다. 최종 공개 릴리스 페이지를 외부 Chrome에 남겼다.

## 유지한 경계와 후속 확인

- 로컬 DB·기존 데이터·JWT·ChatGPT 인증 정보와 실행 중인 로컬 컨테이너는 변경하지 않았다. DB 통합 검증은 GitHub Actions의 일회용 PostgreSQL에서 수행했다.
- 이번 원격 산출물을 다시 로컬 앱에 설치하거나 실행하지 않았다. 이미지 검증은 익명 매니페스트 조회이며 두 아키텍처 컨테이너의 실서비스 기동 검증은 아니다. Linux amd64 바이너리 실행·버전 확인은 릴리스 작업에서 수행했다.
- 실제 사용자 OAuth 로그인·외부 LLM/Splunk 호출·운영 데이터 이전은 수행하지 않았다. 기존 로컬 검증 범위와 구분한다.
- 소스나 바이너리 수정 없이 위 3개 안내 문서와 이 완료 기록만 갱신했다. 최종 결과 기록은 `main`에 후속 커밋하며 이미 발행한 v1.0.0 태그와 첨부 파일은 변경하지 않는다.
