# 2026-10-27 v1.0.0 원격 검증과 발행

## 요청과 실행 범위

사용자가 승인한 `hdhdev-droid/artex-community` 커밋·푸시·v1.0.0 릴리스 작업을 외부 Chrome에서 이어간다. 기존 로컬 DB와 인증 정보는 변경하지 않으며 실제 OAuth 로그인·외부 서비스 연동 검증은 이번 작업에 포함하지 않는다.

## Actions 미실행 원인과 조치

- [10월 24일 기록](2026-10-24-v1.0.0-publication.md)의 원격 미실행 원인은 GitHub가 포크 생성 시 워크플로 실행을 비활성화한 상태였음이 관리자 화면에서 확인됐다.
- 사용자의 실행 직전 승인 후 `I understand my workflows, go ahead and enable them`으로 활성화했고 `Actions Enabled.` 표시를 확인했다.
- 기본 토큰 권한이나 외부 기여자 승인 정책은 변경하지 않았다. 워크플로에 이미 선언된 작업별 권한을 사용한다. 정기 외부 링크 점검 워크플로는 기존 비활성 상태를 유지한다.
- 기능 변경 커밋은 `5ddfc15712b77996ea492045f3370cbdcfe71480`, 이전 발행 준비 기록은 `3f95c38d1d9d36251fea7c160995af8d2d29b9ba`이다.

## 원격 검증과 발행 상태

이 기록을 포함한 커밋에서 일반 CI와 문서 검사를 실행하고, release 워크플로 수동 실행으로 백엔드·프런트엔드 및 5개 플랫폼 패키징을 검증한다. 통과한 코드에 v1.0.0 태그를 발행한 뒤 GitHub Release 산출물과 GHCR 이미지의 실제 발행 결과를 이 파일에 추가한다. 이 기록 작성 시점에는 태그와 릴리스를 아직 발행하지 않았다.
