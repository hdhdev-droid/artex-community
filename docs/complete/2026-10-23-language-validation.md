# 로컬 빌드·테스트 및 5개 언어 화면 검증 완료 — 2026-10-23

## 요청과 검증 경계

2026-10-20에 시작한 언어 감사 후속 검증을 2026-10-23에 이어서 마무리했다.
사용자가 이번 작업에 허용한 로컬 빌드·테스트만 수행했다. 외부 서비스 연결과 DB 변경은 하지 않았다.

- 빌드·테스트는 기존 설치 이미지와 의존성 캐시를 사용한 `--network none` 임시 컨테이너에서 실행했다. 패키지 다운로드는 하지 않았다.
- Go 검증에는 DB 접속 정보·비밀 파일·운영 데이터 볼륨을 전달하지 않았다. DB가 필요한 테스트는 기존 조건에 따라 건너뛴다.
- DB 생성·마이그레이션을 포함하는 `scripts/Test-Dev.ps1`은 실행하지 않았다. 운영 백엔드 재시작과 DB 초기화·복원도 하지 않았다.
- 실제 언어 저장은 설치 공통 DB 설정을 바꾸므로, 화면 확인에는 프로젝트의 기존 `NEXT_PUBLIC_MOCK=1` 데모 기능으로 만든 정적 빌드를 사용했다. 프런트엔드의 실제 설정 선택기와 번역 제공자는 그대로 실행했다.
- 검증 화면은 `localhost:5183`에서 제공했다. 서버는 `/api/`를 거부하고 CSP로 외부 자원·통신을 차단했다. 언어 선택은 데모 응답으로만 처리했다.
- 원본 사용자 입력·증거·저장 로그를 수정하거나 실제 알림·LLM·Splunk 요청을 전송하지 않았다.

## 실제 화면 확인 — 2026-10-23

Chrome에서 최종 정적 빌드를 열고 설정 화면의 선택기를 직접 조작했다.

| 언어 | 선택값과 화면 확인 |
| --- | --- |
| 한국어 | `한국어`, 시스템 설정·사이드바·설명 및 테마 접근성 안내 확인 |
| 영어 | `English`, System Settings 및 영어 메뉴·설명 확인 |
| 중국어 | `中文`, 系统配置 및 수정된 搜索·검색 안내·테마 안내 확인 |
| 스페인어 | `Español`, Configuración del sistema 및 긴 설명의 카드 배치 확인 |
| 일본어 | `日本語`, システム設定 및 일본어 메뉴·설명 확인 |

선택값에 따라 화면 문구가 즉시 전환됐다. 설정 카드에서 겹침이나 가로 넘침은 관찰되지 않았다.
추가로 영어 도구 목록·편집기를 열어 설명 원문 입력란을 확인했고, 저장은 누르지 않았다.
로그 화면의 데모 6개 행과 화면 렌더링을 확인했다. 마지막 로그 화면에서 수집된 브라우저 오류·경고는 없었다.
사용자 편집 원문 보존은 5개 언어 회귀 테스트로 별도 검증했다.

스크린샷·접근성 화면 기록 및 빌드 로그는 커밋 제외 폴더 `work/language-validation/`에 보관했다.

- `screenshots/{ko,en,zh,es,ja}-settings.png`, 같은 이름의 `.txt`
- `screenshots/en-tool-editor.png`, `screenshots/en-logs.png`
- `web-tests-final.log`, `web-build-final.log`, `i18n-final.log`, `ui-build-verified.log`

확인 후 검증용 정적 서버를 종료하고 이번 작업에서 만든 임시 컨테이너 3개와 임시 이미지 1개를 제거했다. 기존 개발 컨테이너·DB 볼륨과 로컬 검증 로그·캡처는 유지했다.
