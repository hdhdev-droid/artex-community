# v1.0.0 버전·베이스 표시 및 Actions 릴리스 검토 — 2026-10-23

## 결과

현재 community 소스의 기준 버전을 `1.0.0`으로 지정했다. `version/VERSION`이 단일 선언이며, 정식 태그 `v1.0.0`은 이 값과 일치해야 한다. 아직 태그 생성·push·Release 발행은 하지 않았다.

### 베이스 확인 근거

- 로컬 `artex-global`의 HEAD: `fdfb7a17b7da5e2de716c0e98475ec77a41c64c6`. community의 최초 포크 기록과 일치한다.
- 로컬 global 태그 `v0.3.15-global.1`의 커밋: `d6964594a0221cd921b85056d604bce9d8ce54df`.
- `git describe --tags --long fdfb7a17b7da5e2de716c0e98475ec77a41c64c6` 결과: `v0.3.15-global.1-9-gfdfb7a1`. 해당 태그 이후 9개 커밋이 포함되므로 태그와 동일한 소스라고 표시하지 않는다.
- 글로벌판 `CHANGELOG.md`의 `0.3.15-global.1` 절은 원본 ARTEX `0.3.15` 기반임을 명시한다. 원본 태그 전체와의 일치 검증을 뜻하지 않는다. 기존 MAINTAINING의 `d003372`는 더 오래된 동기화 기준이므로 이를 직접 포크 버전으로 사용하지 않았다.
- 실제 반영한 ko-plus 기능은 community 추가 변경이며 직접 상류 베이스에 섞어 표시하지 않는다.
- 원격 조회 없이 로컬 Git 및 저장된 변경 기록에서 확인했다.

## 검토 결과와 발행 전 남은 단계

정적 확인: 변경 대상 `git diff --check` 오류 없음. VERSION `1.0.0`, upstream JSON 파싱 및 5개 언어의 새 메타데이터 라벨 존재를 확인했다.

1. **미커밋 변경 주의:** 현재 community HEAD는 포크 기준 커밋이다. 이전 기능 이식까지 포함한 의도한 변경을 먼저 커밋해야 한다. 현재 HEAD에 바로 태그를 붙이면 기능이 누락된다.
2. **발행 트리거:** 해당 변경이 포함된 커밋에 `v1.0.0`을 붙여 origin으로 push할 때 Actions가 실행된다. 이번 작업은 설정과 검토까지이며 원격 작업을 수행하지 않았다.
3. **실행 검증 미실시:** 사용자 규칙에 따라 로컬 빌드·테스트·DB 변경·컨테이너 재시작을 하지 않았다. 워크플로에 검사 단계를 작성한 것과 실제 통과는 다르다. 요청 시 로컬 빌드·테스트 후 발행 여부를 판단할 수 있다.
4. **실제 배포 검증:** 최초 GHCR 패키지 접근 권한, GitHub Actions 실제 실행, 플랫폼별 설치, 업데이트 다운로드·재시작·롤백은 아직 미검증. DB 롤백이나 별도 runner/외부 서비스 설치를 자동 제공하지 않는다.
5. **현재 화면:** localhost:5183은 이전 정적 산출물이므로 새 버전·베이스 표시는 재빌드 후 반영된다.

`2026-10-23-community-versioning.md`의 "버전 번호 미정·별도 VERSION 없음" 상태는 이번 요청에 따라 위 정책으로 갱신되었다. 과거 검증 기록은 당시 결과로 유지한다.
