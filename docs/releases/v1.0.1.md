# ARTEX Community v1.0.1

이 패치에는 v1.0.0 이후의 다국어 표시 수정이 포함됩니다.

## 수정 사항

- MCP 및 스킬 화면의 에이전트 노출 목록과 에이전트 삭제 안내에 기존 기본 에이전트 번역을 적용합니다.
- Auto 기본 설명의 원문 기준값을 바로잡고, 브라우저 제목과 설명이 선택한 언어를 따르도록 수정합니다.
- 기본값과 일치하는 시스템 이름·설명만 번역하며 사용자 지정 이름·설명과 증거 원문을 보존합니다.

## 검증과 설치 범위

- 로컬 프런트엔드 테스트 49개, 5개 언어 번역 키 검사, 정적 빌드 및 TypeScript 검사를 수행했습니다. 자세한 내용은 [작업 기록](https://github.com/hdhdev-droid/artex-community/blob/v1.0.1/docs/complete/2026-11-04-build-verification.md)을 참조하세요.
- 실제 OAuth 로그인, 외부 모델·MCP·Splunk 연결과 실제 진단은 이번 패치 검증 범위에 포함되지 않습니다.
- 기존 Docker 설치의 인증 정보는 교체 전에 [인증 정보 이전 절차](https://github.com/hdhdev-droid/artex-community/blob/v1.0.1/docs/deployment-auth.md)를 확인하세요. 애플리케이션 교체는 DB 또는 데이터 롤백을 제공하지 않습니다.
- 진단 runner와 외부 서비스는 설치 환경에 맞춘 별도 설정이 필요합니다.
