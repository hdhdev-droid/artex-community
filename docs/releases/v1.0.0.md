## Community 변경 사항

- API·소스 진단, 후보 검토, 방어 검증, 침해 조사, Closed-loop 및 보안 로그 소스 관련 코드 통합.
- 한국어·영어·중국어·스페인어·일본어 UI 정리, 사용자 입력·증거 원문 보존.
- 처음 설치한 관리자를 위한 온보딩과 준비 상태 안내. 일반 실행에는 샘플 데이터를 넣지 않음.
- OpenRouter OAuth와 ChatGPT 구독 OAuth 연결·모델 선택·프로필 활성화, 5개 언어 안내.
- 운영 인증 디렉터리 분리, JWT·암호화된 ChatGPT 인증 파일 영속화, 기존 컨테이너 이전 도구 및 손상 시 덮어쓰기 방지.
- community 전용 업데이트 저장소, 버전·상류 출처 표시, 플랫폼별 패키지와 GHCR 이미지 발행 구성.
- AWS 실습 환경은 배포 대상에서 제외.

## 배포 산출물

- Linux amd64/arm64, macOS amd64/arm64, Windows amd64 ZIP 및 `SHA256SUMS`.
- 버전 기록 `VERSION`과 상류 기록 `upstream.json`(각 ZIP 안에도 포함).
- `ghcr.io/hdhdev-droid/artex-community:v1.0.0` 및 `latest` 이미지.

## 설치·검증 범위

기존 설치의 업데이트 주소는 새 community 실행 파일을 먼저 수동 배포해야 전환됩니다. Docker 컨테이너 내부의 프로그램 업데이트는 이미지나 별도 진단 서비스까지 업데이트하지 않습니다. API·소스 진단의 별도 runner 및 외부 LLM/Splunk 연결은 설치 환경에 맞는 별도 설정이 필요합니다.

기존 Docker 설치는 컨테이너 교체 **전에** [인증 정보 이전 절차](https://github.com/hdhdev-droid/artex-community/blob/v1.0.0/docs/deployment-auth.md)를 따라야 합니다. 새 마운트만 추가하면 이전 컨테이너 쓰기 계층에 있던 인증 파일은 옮겨지지 않습니다.

프로그램 교체·롤백은 DB 스키마·데이터 롤백을 제공하지 않습니다. 실제 데이터 이전과 외부 서비스 연결 검증은 기존 작업 범위에서 제외됐으며, 태그 빌드 성공과 별도로 운영 환경 검증이 필요합니다. 로컬 검증 결과는 [2026-10-24 완료 기록](https://github.com/hdhdev-droid/artex-community/blob/v1.0.0/docs/complete/2026-10-24-release-readiness.md)에 기록합니다. 실제 OAuth 로그인은 운영자가 수행합니다.

Actions의 수동 실행은 백엔드·프런트엔드 검증과 5개 플랫폼 패키징만 수행합니다. `version/VERSION`과 일치하는 정식 태그를 push할 때 GitHub Release와 GHCR 이미지를 발행합니다.
